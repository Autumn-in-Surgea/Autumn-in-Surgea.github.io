# 西陆经略 / Autumn in Surgea

v0.1 版离线 Web 回合制策略游戏原型。使用 TypeScript、React、Three.js / React Three Fiber、Zustand 和 Vite。所有模式共用一套游戏规则，规则参考 Polytopia 普通部落体系及公开更新说明；代码、界面和程序化几何模型独立实现。

## 安装和运行

需要 Node.js 22.12+（推荐 22 LTS）及 npm。

```bash
npm ci
npm run dev
```

本地开发和试玩统一使用 `http://127.0.0.1:5173/`。端口被占用时启动会报错，便于保持测试存档的地址稳定。修改源码后，开发页面支持热更新。

```bash
npm test        # Vitest 规则测试
npm run build   # TypeScript 检查及生产构建
npm run verify:pwa # 检查生产包的离线缓存、Worker、安装清单和图标
```

构建输出在 `dist/`。开发页面用于热更新试玩，在 GitHub Pages 验证生产版本的安装、离线启动和更新。首次打开 Pages 等待“可离线使用”后，可以点击“安装游戏”或使用浏览器的安装菜单。完成缓存后，规则、AI、模型和音效在设备上运行。

```bash
npm run bench:ai   # 实际对局与 64×64／11 方压力基准
```

在仓库 Pages 设置中选择 GitHub Actions 后，每次推送到 `main` 都会自动测试、构建并发布到组织根站点。开发网页与 Pages 之间通过导出和导入 JSON 迁移存档。[正式站点](https://autumn-in-surgea.github.io/) · [部署指南](agent/docs/DEPLOYMENT.md) · [PWA 文档](agent/docs/PWA.md)

换设备开发时，克隆已提交并推送的仓库，再执行 `npm ci`。继续原有对局时，在旧设备的主菜单打开「对局历史」并导出 JSON，再用新设备的同一入口导入。测试、详细文档和工具随仓库迁移，本地构建和测试产物可重新生成。更多开发上下文见 [接手指南](agent/docs/HANDOFF.md)。

## 三种模式

| 模式     | 地图                                                                                         | 阵营和城市                                 |
| -------- | -------------------------------------------------------------------------------------------- | ------------------------------------------ |
| 故事模式 | 固定 32×32；中央、西北、北方、南方与东方区域；4 个对手                                       | 使用《设定/世界观.txt》中的五个文明和故事城市名 |
| 自由模式 | 种子决定的噪声地图；可调整陆地、森林、山地、资源、村庄密度和噪声频率；随机、均匀或手动出生点 | 阵营名称可填写，留空随机；城市使用编号     |
| 公平模式 | 旱地、湖泊、大陆、群岛、水世界，使用标准地图预设                                             | 与故事模式共用五国、国别开局和首都名 |

自由与公平的新局可选择 24×24、32×32、48×48。公平最多 4 个不同国家作为 AI 对手，自由最多 10 个 AI 对手。新地图的遗迹生成率为符合条件的陆地格每格 1.0%。自由模式选择“手动设置”后，在预览图上依次选择各方出生点。出生点必须在内部平原或森林上，并保持至少 3 格距离；不合法配置会在开始前显示原因。

故事地图使用固定地理与命名聚落。公平和故事均从同一国别包读取初始科技、单位、星星、首都等级和提示。

公平和自由地图上，可生成资源的山地有 70% 的概率出现金属。自由模式的「非矿资源密度」调整水果、作物、动物、鱼和海星的生成概率。

三种模式默认关闭“快速模式”。国民步兵仍为 0 回合，其余常规兵种和舰船改装按解锁科技等待 1、2 或 3 回合。开启快速模式后，训练即时完成。即时出场的单位本回合不能主动行动，按期交付的单位在己方回合开始时即可行动。订单交付前可取消，按剩余回合比例退还已付星星，向下取整。下单回合结束前可按差价改训，城市中心被占用时订单保留到能交付的回合。

快速模式关闭时，国民步兵每回合维护费 1 星，其余常规兵种按科技层级付 1、2 或 3 星，重型装甲车、木筏等特殊单位免维护费。顶部星星栏显示扣除预留维护费后的可支配余额及净收入。点击星星栏可查看预算，并用「超支」开关动用预留款。维护费仍按单位出场先后在回合结束时扣除。欠费单位停用一个己方回合，随后可额外支付一次维护费激活，错过期限则自动解散。

## 规则与内容

- 五分支、三个层级、25 项标准科技；研究费用随城市数量增长，战地勤务提供折扣；支持反向研究相邻科技。
- 星星经济，资源采集，城市人口、等级、容量和按等级选择的升级奖励。
- 标准地块与资源：田野、森林、山脉、浅水、海洋；水果、动物、作物、金属、鱼、海星。
- 国民步兵、轻骑兵、战壕工兵、猎兵、突击步兵、野战炮队、胸甲骑兵、战地军医、便衣侦探，以及重型装甲车、地下突击队和海军体系。
- 由生命比例、攻防和地形计算的确定性战斗；反击、突进、逃脱、连续攻击、老兵、治疗、转化、隐身、渗透及运输。
- 农场、伐木屋、矿场、风车、锯木厂、锻造厂、市场、港口、神庙、桥梁和纪念碑；道路与城市连接。
- 村庄和敌方城市占领、遗迹探索、灯塔、探索迷雾；隐藏单位按隐身规则显示。
- 外交、和平提议、大使馆；统治和 30 回合完美对局。
- 自由模式可对各方指定通用开局预设，默认随机。故事和公平开局采用 [国别包](src/nations/README.md)。
- AI 使用相同 Action 校验和结算接口，在 Web Worker 中执行；动态军队目标和行动预算支持 64×64、10 个对手。简单与普通具有不同的战术、经济和推演能力。
- 地图拖动、缩放、单位移动与攻击反馈、快捷键、自动存档及 JSON 导入导出。

## 操作

1. 开始新游戏，选择模式、地图和对手，点击“开始游戏”。
2. 点击自己的单位，再点击绿色地块移动。点底栏中的单位特性可查看规则说明，特性旁显示晋升所需的击杀进度。首次点击可换位的相邻友军时，棋盘只框出两支单位所在格。再点一次确认换位。点可攻击的敌军后，底栏会显示伤害、反击和双方生命值预测。再次点击目标所在格即攻击，按 `Esc` 退出预览。
3. 点击城市，灰色虚线标出其领地。在底栏选择要训练的兵种。同一格有单位时，点击同一位置可在单位与城市或地块之间轮换。采集和建设直接在对应地块上操作。
4. 单位进入村庄或敌城，驻守到自己的下个回合。敌城在单位抵达时进入围城，城模压暗并出现火焰和烟。单位头顶出现旗帜时，点击旗帜打开单位面板，再点“占领”。进入遗迹的单位也要等到下个己方回合才能探索。
5. 点击“科技”打开星形科技树，拖动可查看其他分支。手机双指捏合缩放，桌面使用滚轮，点“显示完整科技树”可看全图。首次点一个节点查看简介与费用，再点同一个可研究的节点确认。
6. 城市升级时，点击城上方的双箭头选择奖励。也可以按 `Enter` 定位待领奖城市。所有升级奖励选完后即可结束回合。达到晋升条件的单位上方会显示提示，点击可打开单位面板。
7. 点击“结束回合”后，己方受伤且还拥有完整行动的单位自动恢复，然后 AI 依次行动。统治模式消灭全部对手，完美模式进行 30 回合后结算。

鼠标左键拖动平移，滚轮缩放。设置中的“详细信息”可将城市人口条和收入放在棋盘城牌或选择面板。等级始终显示在选择面板。人口条每格对应一个单位位，填色显示人口进度，圆点显示已占用的单位位。“资源显示”可开关可采集和可开发资源的描边。

底栏的设置可以重置视角。「界面主题」可以跟随系统，或固定使用象牙白浅色与深蓝深色，主菜单和对局界面同步切换。返回主菜单会保存当前对局，方便之后继续。开始新游戏会覆盖自动存档。`N` 选择下一单位，`T` 打开科技，`Esc` 取消选择或关闭面板，`Enter` 在奖励选完后结束回合。

## AI 与难度

| 能力 | 简单 | 普通 |
| --- | --- | --- |
| 探索、占领、训练、建设、研究 | 支持，偏重立即收益 | 支持，结合局势、邻接产出和发展收益 |
| 战斗 | 单位逐个选择眼前收益 | 优先集火、解围、高价值目标 |
| 防守 | 基础伤害与反击判断 | 预测可见敌军威胁，驻城、回防和撤退 |
| 行动推演 | 无 | 每方每回合最多 72 次规则调用，比较移动后攻击及生存风险 |
| 军队规模 | 较少、发展较慢 | 随城市容量、探索需求和可见敌情增长 |

两档均无额外资源或规则豁免。隐藏单位不用于战术评分，实际行动必须通过规则层验证。导航支持陆地、港口、运输和登陆；科技选择会考虑资源与海军需求。规则结果、随机扰动和 AI 行动均可复现。

AI 的常规行动预算为 `单位数 × 4 + 城市数 × 7 + 地图边长`，最低 48、最高 1600。预算耗尽后，AI 仍会选完升级奖励并结束回合。领奖和结束回合使用与玩家相同的规则，单独结算。普通难度采用有界启发式，复杂海战、远期外交和超大军团仍有调优空间。实际测试规模及耗时见 [AI 实测记录](agent/docs/AI_BENCHMARK.md)。

Worker 计算期间可以打开设置、拖动和缩放。返回主菜单会中断当前计算，继续游戏会从已保存的回合状态重算；新游戏、读档不会被旧 Worker 结果覆盖。每个 AI 完成后保存检查点，页面关闭后可恢复；线程异常显示“重试 AI 回合”，不会绕过对手或退回主线程进行长计算。

## PWA 更新和存档

主菜单和设置显示离线就绪状态及安装入口。更新下载后显示“更新并重启”，只在用户点击、存档成功且 AI 空闲时重载。其他窗口激活更新不会强制重载正在游玩的窗口。

主菜单的「对局历史」保存最近十次开局的时间、设置和种子，可点击种子旁的按钮复制。当前对局可在同一页面保存、导出为 JSON，或从 JSON 导入。

存档保留 schema 2，与 v0.2 兼容。对局历史与存档都通过 localStorage 保存，程序缓存独立保存。安装时会申请浏览器持久存储，但不能阻止用户清除站点数据；重要对局请导出备份。本版没有引入 Tauri、Electron 或后端。

## 规则依据和边界

重点参考官方 Wiki 的科技、单位、战斗、城市、建筑及 2025 年平衡更新，并核对官方商店截图中的布局与操作密度。兵种数值、伤害算例及与原作的核对范围见 [战斗核对](agent/docs/COMBAT_AUDIT.md)。其他规则的来源与版本取舍见 [规则参考](agent/docs/RULES_REFERENCE.md) 和 [已知差异](agent/docs/KNOWN_DIFFERENCES.md)。

“公平模式”是本项目的模式名称，不表示获得了原作的生成器或 AI。地图算法、AI 评分、几何模型与布局是独立实现；不能声称原版源码级或逐像素完全复刻。普通部落的区域资源倍率、原作完整难度体系、特殊部落科技/单位、联网、皮肤和成就体系不在当前版本范围。公开资料有新旧字段冲突，已在规则文档记录取舍；未确认的细节不应视为原版行为证明。

存档使用 schema 2，与先前包含世界潮汐和现代兵种的 schema 1 不兼容。新存档使用独立浏览器键，不覆盖旧版本键。清除网站数据会清除本地存档，需要保留的对局请从主菜单的「对局历史」导出。

## 目录

```text
src/
  branding.ts           # 中英文显示名称
  assets/fonts/         # 生产版与离线 PWA 共用的本地字体
  game/
    types.ts            # 状态和统一 Action 类型
    data/config.ts      # 科技、兵种、建筑、开局配置
    map/                # 噪声地图与固定故事地图
    rules/engine.ts     # 行动验证、战斗、经济与胜负
    ai/                 # 可见信息、导航、战术、经济、难度与行动预算
  nations/              # 各国数据、徽章和模型入口
  scene/                # Three.js 渲染、地图及动画
  store/                # Zustand、版本化存档与验证
  workers/              # AI Worker、通信与取消/超时处理
  pwa/                  # 安装、离线状态、手动更新
  ui/                   # 菜单、设置、操作栏与科技树
  styles/main.css
  App.tsx
agent/
  docs/                 # 接手指南、规则参考、发布与验收记录
  tests/                # 规则、AI、存档和界面逻辑回归测试
  scripts/              # PWA 产物检查与 AI 基准
AGENTS.md               # 自动化开发代理的入口
public/icons/           # 原创 PWA 安装图标
public/licenses/        # 随应用分发的字体许可证
设定/世界观.txt               # 用户提供的设定，保持原文件
```

规则层不依赖 React 或 Three.js。随机结果使用种子，可用于复现地图和对局问题。大地图基础地块使用实例绘制，地图装饰按视口与缩放裁剪，避免同时绘制全部高细节模型。

## 验证

新增 AI 战术与难度差异、隐藏信息、72 单位完整行动、64×64／11 方中期局面、逐动作合法重放、Worker 取消与重试、PWA 缓存和更新生命周期测试。保留已有的地图、经济、移动战斗、完整征服、三模式积分及存档回归。

生产构建仍有 Three.js 依赖块大小提示。详细测试结果、实际离线对局和用户的安装实机反馈见 [验收记录](agent/docs/VERIFICATION.md)。

标题优先使用系统宋体粗体，其他文字和标题回退使用圆度 40 的 Resource Han Rounded。配色来源、字体和动效见 [界面配色与动效](agent/docs/VISUAL_STYLE.md)。
