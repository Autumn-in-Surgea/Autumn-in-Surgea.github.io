# 西陆经略 / Autumn in Surgea 开发交接

当前代码版本为 **0.1**。这是离线单机的轻量回合制 4X 游戏，已经可以开局、发展城市、与 AI 对战、结算胜负、保存与读档。

## 换设备继续开发

1. 在旧设备查看 `git status --short`，用 `git add -A` 暂存源码、运行资产、锁文件、配置和 `agent/`，核对 `git diff --cached --stat` 后提交并推送。首次提交整款应用时，以完整文件清单为准。若继续已有对局，从主菜单进入「对局历史」导出存档 JSON，单独复制文件。[项目仓库](https://github.com/Autumn-in-Surgea/Autumn-in-Surgea.github.io)
2. 在新设备克隆或更新仓库到同一提交，使用 Node.js 22.12 或更新版本，运行 `npm ci` 和 `npm run dev`。Vite 开发地址固定为 `http://127.0.0.1:5173/`。如需继续旧对局，在新设备计划使用的游戏入口中打开「对局历史」，导入存档。
3. 本地开发和试玩都用 5173 端口，端口被占用时启动会报错。用 `npm test` 检查规则及生命周期回归，运行 `npm run build` 和 `npm run verify:pwa` 验证静态产物。生产版的 PWA 安装、离线启动和更新在 GitHub Pages 验收。

| 忽略项 | 用途与恢复方法 |
| --- | --- |
| `node_modules/` | 本机依赖，由 `npm ci` 按 `package-lock.json` 安装。 |
| `dist/` | 静态发布产物，由 `npm run build` 重建。 |
| `.DS_Store` | macOS Finder 生成的目录元数据。 |
| `*.tsbuildinfo` | TypeScript 增量构建缓存，下次构建可重建。 |
| `artifacts/` | 本机截图、测试存档、行动样本、旧测试工具的临时打包输出。需要保留原截图或对局时单独复制。 |

`artifacts/` 无需随 Git 上传。以前浏览器验收用的截图与存档样本可按需从旧设备复制。`public/` 下的标识与 PWA 图标是游戏运行资产，应随源代码提交。公共 GitHub 仓库中已提交的 `设定/世界观.txt` 和 `agent/` 可随源码查看，Pages 工作流只上传 `dist/`。

## 已定设计

- 故事模式的新局使用固定 64×64 地图、45 座命名城市和五个世界观文明。西陆海岸收拢，南方半岛位于大陆中南部。帝国南部的平原和河口城群加密，北部草原与西部高原保留稀疏节点。大台位于主河入海口南岸，长守位于西部高原与半岛交界。五国开局拥有全图视野、彼此相识，沿用各自原定的起始资源。地理原稿在 `src/game/map/storyGeography.ts`，`src/game/map/story.ts` 生成地貌细部和逐格河道后，将地理原稿整体向北、向西各平移 4 格。灯塔固定在棋盘四角。旧故事存档沿用存档内的地图和视野。地理原始资料见 [世界观.txt](../../设定/世界观.txt)。
- 地图编辑器以 45 城的六城迁址方案为初始草稿，使用同一个 `GameScene` 渲染。地形、城市和名称编辑规则在 `src/game/map/editorDraft.ts`，草稿单独保存到 `surgea.map-editor.v1`，支持 JSON 导入导出。编辑器打开时以全图取景，对局开局仍以玩家首都取景。
- 自由模式用随机种子和噪声参数生成地图，允许调整地形、资源、聚落密度，以及随机、均匀或手动安排出生点。公平模式用标准地图预设和出生资源保底。公平与故事共用五个国家及国别开局，公平最多选四个 AI。自由模式可用五个国家之一开局，也可自定义玩家阵营名称和开局。最多十个 AI，均可分别设置名称与开局。随机地图的城市与村庄落在平地，手动出生点可从平原或森林中选取。随机地图的新局尺寸为 24×24、32×32、48×48。
- 三种模式共用同一规则引擎。优先参考 Polytopia 普通部落公开规则，保存其轻量节奏和可预判的科技、战斗、地块、建筑语义。程序化几何模型、界面、地图和代码独立制作。现有 25 项科技、星星经济、城建、升级、海军、迷雾、外交与两类胜利条件均可游玩。官方资料冲突、各处实现取舍和公平模式生成边界见 [规则依据](RULES_REFERENCE.md) 与 [已知差异](KNOWN_DIFFERENCES.md)。
- 三种模式都默认关闭快速模式。国民步兵即时出场、维护费 1 星，常规兵种与舰船改装按科技层级等待 1–3 回合并计同级维护费，特殊单位免除两者。即时出场的单位耗尽本回合移动和行动，延迟交付的单位到场可行动。交付前可按剩余训练比例取消退款，下单回合可改训。星星栏显示净收入和可支配余额，点开可用「超支」开关。默认预留维护费，结束回合再按出场先后扣除。欠费停用一回合，激活窗口过期解散。
- 用户保留世界观文案创作。菜单和操作提示采用直接表述，减少细小的辅助文字。世界潮汐、政策和自定义文明数值加成已从当前规则移除。改动优先满足可玩性、规则完整性和操作体验。
- 游戏界面使用深蓝、象牙白与旧金，放大界面与地图文字，在桌面和窄屏保留主要操作入口。移动沿规则层合法路径插值，攻击、受击、训练、建设和城市变化提供反馈。AI Worker 记录行动当时可见的移动路线与交火。投射物、反击和死亡按命中时刻播放；迷雾中的射手只在目标格显示来袭武器。系统偏好和游戏“减少动画”设置均可生效。详见 [界面配色与动效](VISUAL_STYLE.md)。
- 己方城市有升级奖励时，城上方显示双箭头，结束回合入口与 `Enter` 会打开待领奖城市。多座城市同时升级时可以逐城处理，每座按升级顺序选择。领取人口触发的新等级也必须在本回合选完。AI 通过同一规则领取，常规行动预算耗尽后仍会结清奖励。存档继续使用 schema 2，保留待选等级队列。
- 单位可以实际占领时，模型上方显示旗帜。达到晋升条件时显示奖章。遗迹可探索时显示罗盘，欠费单位进入重新激活窗口时显示回转箭头。点击标记打开单位面板，再执行对应动作。棋盘提示限定在己方回合的可见地块。对局界面已移除左上角事件日志与信息面板坐标。标题优先用系统宋体粗体，回退、其他界面与地图标签使用圆度 40 的 Resource Han Rounded。对局 UI 设 20px 与 14px 两档，首屏单独放大标题与按钮，详情见 [界面配色与动效](VISUAL_STYLE.md)。
- 对照原作战斗时先查兵种数值表、伤害与反击算例，以及仍需客户端回放验证的情况。[普通部族战斗核对](COMBAT_AUDIT.md)

## 代码定位

| 位置 | 维护要点 |
| --- | --- |
| `src/game/` | `types.ts` 定义状态和 Action，`data/config.ts` 管理配置，`map/` 负责种子与地图，`rules/engine.ts` 负责验证、结算和合法移动路径。规则层可独立测试。 |
| `src/nations/` | 每国维护中英文名、首都、开局配置、提示、徽章、棋盘色、模型和地块变体。地块变体开图时绑定坐标并保存，五国目前采用帝国地块。见 [国别包说明](../../src/nations/README.md)。 |
| `src/game/ai/` 与 `src/workers/` | AI 经同一 Action 接口行动。普通档会权衡攻占城市的长期收入、行军时间与风险，并预测研究后的开发、城市升级、兵种训练和维护费。简单档偏重眼前收益，两档都受行动预算约束。注意维持迷雾下的知识边界、Worker 的取消与重试能力。 |
| `src/store/` | Zustand 驱动逐步行动。Worker 给出命令计划，主线程逐条结算，可见动作等场景确认播放完成。事件弹窗等待玩家确认，未读提示随存档保存。切换对局会取消旧计划。`save.ts` 验证 `autumn-v2` JSON 和状态引用。 |
| `src/scene/` | R3F 地图、程序化模型、裁剪和动画。场景读取每一步的前后快照，按渲染时钟播放可见动作，结束即推进。大地图的基础地块用实例化渲染，精细模型按视窗加载。海面、平地、山地的三级落差统一配置在 `terrainElevation.ts`。城市每升两级更换领内设施雕刻，三档封顶，换模跟随行动时钟。 |
| `src/ui/`、`src/styles/` 与 `src/App.tsx` | 开局、HUD、科技面板、设置、输出反馈和输入。改动后检查桌面与窄屏布局，以及棋盘和平移、缩放是否正常。 |
| `src/pwa/` 与 `vite.config.ts` | Workbox 生成生产缓存，包含 AI Worker。安装与更新状态由前端统一管理，点击“更新并重启”时先保存。相对资源路径和 PWA 作用域支持项目子目录。 |
| `agent/docs/` | 设计取舍、规则参考、部署和验收记录。 |
| `agent/tests/` | `npm test` 执行的 Vitest 回归断言。地图提示见 `map-badges.test.ts`，升级、读档和 AI 领奖见 `city-upgrade-turn.test.ts`，战斗核对样例见 `combat-audit.test.ts`。 |
| `agent/scripts/` | `npm run verify:pwa` 检查离线资源，`npm run bench:ai` 测量 AI 性能。开发服务器可打开 `/agent/scripts/fish-atlas.html` 烘焙鱼群图集并预览动画。 |

## 离线与发布状态

开发与 Pages 共用同一套游戏代码。开发模式使用热更新。安装版从 Pages 下载静态构建，首次缓存完成后可离线运行。当前存档通过 `localStorage` 保存，键为 `four-shades-of-autumn.save.v2`。最近十次成功开局的设置和种子另存于 `four-shades-of-autumn.match-history.v1`。两者均按协议、主机和端口隔离。不同设备、浏览器资料及不同地址之间通过已导出的 JSON 搬运对局。

推送到 `main` 会触发 `.github/workflows/deploy-pages.yml`，先安装依赖、跑测试、构建和校验缓存，再发布 `dist/`。目标站点为组织的根地址 `https://autumn-in-surgea.github.io/`。仓库 Pages 的发布源使用 GitHub Actions，保留手动发布入口。明细见 [部署指南](DEPLOYMENT.md) 与 [PWA 运维](PWA.md)。

规则、生产构建与离线缓存由 GitHub Pages 工作流验证。Chrome 桌面和触屏视口覆盖城市升级与晋升提示、训练中止退款、星星预算、单位特性弹窗与界面主题切换。规则测试覆盖快慢模式完成征服和慢速 64×64／10 AI 行动回放。以往另验证过二次点选换位、领地提示、生产版占领、断网读档推进回合及完整离线对局，系统安装及独立窗口启动由用户确认。其他记录见 [验证记录](VERIFICATION.md)，AI 调优可对比 [AI 基准](AI_BENCHMARK.md)。
