## 五国开局与舰船绘制

Chrome 实际从开局菜单进入 48×48 公平模式的诺斯塔、32×32 故事模式的铃亚和 24×24 自由模式。核对了五国双语名称、徽章、首都、科技和初始单位，具名开局直接出现所选国家的提示。港口与舰船重叠时，WebGL 像素和实际点选均命中船身，随后可驶入浅海。旧匿名公平对局及旧尺寸可继续读档。

## 保留的实现限制

- AI 为确定性、有界的启发式与局部推演，不是全局最优求解器。普通难度的战略质量仍需更多实际试玩调整。
- 每方行动硬上限为 1600，极端超过当前压力测试规模的存档仍可能达到预算；最终结束回合始终执行。
- AI 预测可见敌军通行时保守假定攀登、捕鱼、航海，不读取敌军真实研究清单。预测可能高估敌军威胁，实际行动仍严格执行真实规则。
- 经济阶段新获得的巨人留待下回合调度。
- 存档仍使用 localStorage；压力存档约 1.1 MB，保存失败会显示提示，可导出 JSON 备份。跨设备同步、IndexedDB 多存档库没有在本轮引入。
- PWA 离线依赖已成功缓存且站点数据未被清除。没有引入 Tauri、Electron 或服务端计算。
