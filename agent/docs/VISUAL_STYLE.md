# 界面配色与动效

2026-11-18：本轮调整字号、配色与操作反馈，不改变科技、战斗或经济规则，不增加文学性界面文案。

## 配色依据

选用艺术配色网站 [Color Lisa](https://colorlisa.com/#V) 收录的 Johannes Vermeer《The milkmaid》色板作为基底。网站给出的五色为 `#022F69`、`#D6C17A`、`#D8D0BE`、`#6B724B`、`#7C3E2F`。

这是设计选择：深蓝与暖金能承接宫廷感，石色与绿能融入地形，赭红适合重要反馈。为了在小屏幕与三维地图上长期阅读，实际 UI 使用经明度、饱和度调整的衍生色，而不是宣称原作使用了下面的屏幕色值。

| 用途 | 屏幕色 |
| --- | --- |
| 主操作、墨青 | `#254D5A` |
| 正文 | `#243C42` |
| 面板、象牙白 | `#F5F0E3` |
| 旧金强调 | `#B59A55` |
| 绿与地形辅助色 | `#4D7162` |
| 危险、赭红 | `#914C3E` |
| 环境背景 | `#D5DCD6` |

大面积以暖浅色面板、冷灰环境为主；墨青组织操作，金色只用于细节与重点。阵营仍保留各自辨识色。

## 字体与地图操作

对局与常规面板使用两档字号：大号 `20px`，小号 `14px`，由 `src/styles/main.css` 中的 `--font-size-large` 和 `--font-size-small` 维护。主菜单是字号例外。中文和英文标题使用源流明体丹版粗体，中文在常规窗口为 52–94px、英文为 21–32px。标题与等宽等高的主菜单按钮居中竖排，每行一个按钮。对话框标题也使用丹版粗体；按钮、正文、对局顶部和地图标签使用 Resource Han Rounded 简体中文版，圆度固定为 `40`。顶部各项统一小号，用字重和颜色区分重点。城名和兵人血量与棋格等比缩放，战斗反馈使用 14px 的屏幕字号。

丹版来自 [源流明体 v2.100](https://github.com/ButTaiwan/genryu-font/releases/tag/v2.100) 的 `otf/TC/GenRyuMin2TC-B.otf`（上游 `TC` 为丹版，`TW` 为月版）。圆体来自 [Resource Han Rounded v1.910](https://github.com/CyanoHao/Resource-Han-Rounded/releases/tag/v1.910)，用 OpenType 的 `ROND` 轴生成 `40` 的 WOFF2 子集。生僻自定义名称可回退到系统字体。两套字体和各自的 SIL OFL 1.1 许可证随构建提供并预缓存。

重新生成网页字体时，用 FontTools（含 WOFF2/Brotli）从上述版本取源文件，保留 UI 用字与基本拉丁字符，圆体另外保留 GB 2312。圆体网页子集移除仅用于垂直排版的表与 `BASE` 表，按原顺序规范化 GPOS 的字形索引，再用 `instantiateVariableFont(font, {"ROND": 40, "wght": (400, 700)})` 生成保留字重轴的版本。修改后的内嵌字体使用独立字体家族名称。

开局配置、设置、科技树、外交、地图和详情使用全屏页面。新增菜单优先采用同样的贴边页面。地图生成与预览移到开局表单末尾，公平模式直接选择标准地图预设。对局棋盘位于两条固定高度的通栏之间。紧凑的上栏显示回合、星星、收入、城市、单位和分数，底栏在一级菜单和所选对象的操作之间淡入淡出，操作按钮保持固定宽度，整栏放不下时横向滑动。训练列表按已解锁科技显示兵种。“结束回合”固定在底栏右侧；有待选升级时会打开对应城市的奖励。

首页背景直接使用 `设定/bg.png`，通过 CSS `cover` 随视口等比裁切。标题与操作组直接叠在背景图上，中央使用淡出的半透明渐变提高可读性。低高度窗口收紧行距，必要时可纵向滚动。科技树在横屏和竖屏共用同一星形布局，拖动平移，双指或滚轮缩放，亦可用全图按钮回到总览。

只有城市显示名称，名牌沿屏幕中线放在模型下方，使用 48% 不透明度的深灰底。生命值使用无底色的象牙色粗体和深色描边，低血量使用浅珊瑚色。金色双箭头显示城市有待选的升级奖励，青绿色旗标显示驻军已可占领所在聚落。点击徽标打开对应操作。城内即使有驻军，点击升级提示也会打开城市面板。结束回合按钮与 Enter 会先定位尚未完成选择的城市。

第一次点可攻击的目标时，底栏直接显示预计伤害、反击与双方生命值变化，目标棋子脚下显示红色光圈。再次点同一目标格执行攻击。改点另一名可攻击的敌军会切换预估，按 Esc 会退出预估并保留攻击者的选择。

## 棋盘与棋子

棋盘采用削边格面、木质边框与黄铜嵌线。正交相机锁定俯仰角和方位角，拖动平移，滚轮和双指捏合缩放。选中格用金色柔光圈边，攻击目标用珊瑚红，移动范围用绿色细边。五种地形各有一种底色，三维棋盘、开局预览和小地图共用 `src/scene/terrainColors.ts`。浅海和深海各自通铺。近景中，部分空平原有几片低草，空水面有一对浅色弧纹。点缀按格子位置固定，避开玩家已知的资源、建筑和道路，两组共享实例随远景隐去。山地、平原与海洋共用三级台座高度。以平原为基准，山地高出 0.12 格宽，海面低 0.105 格宽。森林与平原同高，深浅水同高。单位、弹道、道路、建筑和徽标共用 `src/scene/terrainElevation.ts`。选中、移动、攻击光圈和势力边界在独立图层绘制。边界遇到台阶时沿立面接合。

棋盘通过透明画布呈现在银河底图上。场景采用略偏中性的照明，模型颜色在 sRGB 下微调明度与饱和度。其他阵营的可见领地及其中的模型轻微压暗，已用尽行动的棋子采用单独的行动暗度。

己方领土内符合采集条件的可见资源使用细金边提示。描边沿资源模型轮廓绘制，林地里的动物和背景树木各用自己的模型。提示取决于科技、领地和驻军等采集条件，星星余额只影响实际采集。

陆军共用奥匈式蓝灰制服、红立领，面部只留一整块肤色切面。步兵戴折边野战帽，两个骑兵分别戴骠骑兵筒帽和枪骑兵四角帽，守卫的大盾单独保留。制服的参考来自奥地利馆藏野战帽和骑兵礼服。[萨尔茨堡博物馆藏 M.1908 野战帽](https://sammlung-online.salzburgmuseum.at/detail/collection/401e934a-baa3-4491-b1d3-cdf657f6d39f) · [洛克韦军事博物馆奥匈礼服展](https://vojaskimuzejtabor.eu/EN/zacasna-razstava-ao-vojaska-parada.html)

侦察船和撞击艇为木质尖艏、外露明轮的小型帆船。侦察船用高帆与艏弩，撞击艇用低横帆与艏部撞角。轰炸舰、无畏舰采用近一格长的高舷铁甲舰轮廓，通过宽单烟囱与双烟囱辨认。[横须贺三笠纪念舰](https://routemuseum.jp/en/theme/navy/b05/)

六种资源都使用多面低模。果树、鱼群和林鹿是基础采集物，果树宽约 0.326 格，保留三个红果，林鹿放在树丛靠相机的一侧。作物与矿石供二阶科技建设农场和矿场，采用金色麦穗与深岩上的浅金矿脉。导航解锁采集海星，珊瑚色腕部在深水上最醒目。这是美术层次，沿用已有的资源分布、显示与采集规则。实现位于 `src/scene/landscape.ts` 与 `src/scene/tidalResources.ts`。运行 `npm run dev` 可用[图集试片](http://127.0.0.1:5173/agent/scripts/fish-atlas.html)烘焙当前的多面鱼群；对局直接绘制网格。

## 阵营资产

`src/factions/registry.ts` 集中登记故事文明原有的设定文字、首都名称、配色、开局配置及 `modelSet`。开局、文明选择页和地图使用同一条目。故事模式根据每个对象当前所有者的 `Player.civilization` 解析资产，自由、公平模式和无主地块使用 `neutral`。阵营色继续取自存档的玩家记录，对象易主后跟随新所有者。各方本版都使用 `danubian` 模型套件。

要增加专属内容，可在 `src/factions/<id>/` 放置配置、模型、图片及文本，从登记表引入本地模块。徽章图片通过 `images.emblem` 供选择页和对局 HUD 自动使用。可选的 `missionTree` 支持节点编号、标题及前置关系，任务内容及运行逻辑留待设计。增加模型套件时，在 `ModelSetId` 与 `src/scene/factionModels.ts` 中登记，使用现有套件的工厂即可逐件覆盖棋子、城市、建筑与资源。兵种雕刻见 `src/factions/danubian/units.ts`。城市雕刻见 `src/factions/danubian/cities.ts`。各级建筑直接落在棋格表面，街巷露出平原。主要地标的细部与旗帜采用当前阵营色。无主村落使用独立的朴素造型，城市升至七级及以上沿用六级模型，首都旗与城墙另按实际状态绘制。每座城市合成一个网格，同一套件、颜色、等级段和设施状态的城市共享几何。规则与 Worker 只读取清单数据，Three.js 模型从渲染端引入。

## 动效原则

移动和行动分别按兵种规则判断。弓箭手移动后如有可攻击目标，会保持选中；骑手和骑士也可继续合法的撤离或连击。用尽可用动作才取消选中并压暗棋子。陆军棋子在地块与建筑之后绘制，移动经过山体、树林或建筑时保留完整轮廓。兵种内部和相邻陆军棋子仍按深度排序，与棋子重叠的点击优先选择可见棋子。舰船的初始朝向在屏幕上与水平线约成 45°，移动时沿路径转向，攻击时朝向目标，动作结束后保留朝向。

规则先确定操作结果，渲染层在前后快照之间做短过渡。移动、攻击朝向、受击、死亡与训练反馈由场景负责；界面按钮、弹窗、侧栏和进度条使用短 CSS 过渡。动画不参与规则计算，也不延迟资源与存档结算。

城市、建筑和道路的出现、易主、替换及升级由行动前后两个快照确定。换模先下沉约 0.36 秒，停顿 0.065 秒，再上升约 0.54 秒，露出的部分随地表高度裁切。同一行动引起的城市与附属设施变化同步展示，后续行动等待整步完成。读档与拖动镜头直接显示当前造型。具体见 `src/store/structurePlayback.ts` 和 `src/scene/TileScenery.tsx`。

设置中的“减少动画”保留为可选入口。迷雾之外的敌人行动不可通过过渡动画泄漏；大地图按可见区域渲染，避免为了动画挂载整张地图的单位模型。

近战棋子先后撤蓄力，再加速冲向对方，底座或船艏接触时结算画面上的伤害。受击棋子会后退或倒下，进攻棋子回弹，反击时交换角色。进攻距离考虑两枚棋子的体量与驻军站位。先移动再攻击时，动作沿同一时间轴衔接。弓箭手、投石车、侦察船和轰炸舰仍用箭矢、石弹、弩矢与炮弹，伤害表现与落点同步。射手或路径被迷雾遮挡时，来袭方向取与其坐标无关的短轨迹。减少动画时保留武器名和伤害。战斗跟随场景播放时钟，在低帧率下会放慢，切换至后台会暂停。
