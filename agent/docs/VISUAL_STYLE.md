# 界面配色与动效

2026-11-18 更新对局界面、菜单尺寸与触屏操作。

## 配色依据

选用艺术配色网站 [Color Lisa](https://colorlisa.com/#V) 收录的 Johannes Vermeer《The milkmaid》色板作为基底。网站给出的五色为 `#022F69`、`#D6C17A`、`#D8D0BE`、`#6B724B`、`#7C3E2F`。

这是设计选择：深蓝与暖金能承接宫廷感，石色与绿能融入地形，赭红适合重要反馈。为了在小屏幕与三维地图上长期阅读，实际 UI 使用经明度、饱和度调整的衍生色，而不是宣称原作使用了下面的屏幕色值。

| 用途 | 屏幕色 |
| --- | --- |
| 对局通栏和菜单页眉 | `#22394F`、`#101F32` |
| 正文 | `#243C42` |
| 面板、象牙白 | `#F5F0E3` |
| 旧金强调 | `#B59A55` |
| 绿与地形辅助色 | `#4D7162` |
| 危险、赭红 | `#914C3E` |
| 环境背景 | `#D5DCD6` |

浅色界面采用象牙白细纹、深蓝文字和旧金镶边。深色界面采用深蓝底与象牙色文字。主菜单、对局上下栏、选中面板、全屏菜单和特性弹窗共用主题，可跟随系统或由玩家手动切换。

棋盘、开局预览与地图编辑器共用地块材质的色值。地图参考 [Natural Earth 晕渲地形](https://www.naturalearthdata.com/downloads/10m-raster-data/10m-cross-blend-hypso/) 对陆地自然色的处理，以及 [瑞士地形图](https://www.swisstopo.admin.ch/en/map-content) 用岩层与晕渲区分地貌的做法。平原、森林、山地、浅水和深海依次使用橄榄绿 `#7d895c`、松绿 `#4f6b55`、暖岩灰 `#827668`、铜青 `#527a77` 和墨蓝 `#314d62`。岩层、树冠、底座和水纹用相近的暗色分层。果实、麦穗、矿脉、林鹿、鱼群和海星分别用赭红、旧金、铜色、栗棕、青银和陶红作局部辨识，工地上的原生资源和收获动画共用这些模型色值。

## 字体与地图操作

对局与常规面板使用两档字号：大号 `20px`，小号 `14px`，由 `src/styles/main.css` 中的 `--font-size-large` 和 `--font-size-small` 维护。主菜单是字号例外。中文和英文标题优先使用系统宋体粗体，中文在常规窗口为 52–94px、英文为 21–32px。标题与等宽等高的主菜单按钮居中竖排，每行一个按钮。对话框标题沿用同一套宋体配置；按钮、正文、对局顶部和地图标签使用 Resource Han Rounded 简体中文版，圆度固定为 `40`。顶部各项统一小号，用字重和颜色区分重点。城名和兵人血量与棋格等比缩放，战斗反馈使用 14px 的屏幕字号。

标题按系统字体可用性依次尝试 Songti SC、STSong、SimSun 等宋体，以及常见的 Noto Serif CJK SC。标题使用 700 字重，只有常规字重的系统字体允许合成粗体。缺少系统字形时使用 Resource Han Rounded。圆体来自 [Resource Han Rounded v1.910](https://github.com/CyanoHao/Resource-Han-Rounded/releases/tag/v1.910)，用 OpenType 的 `ROND` 轴生成 `40` 的 WOFF2 子集，随其 SIL OFL 1.1 许可证一同分发与预缓存。

重新生成网页字体时，用 FontTools（含 WOFF2/Brotli）从上述版本取源文件，保留 UI 用字、基本拉丁字符和 GB 2312。圆体网页子集移除仅用于垂直排版的表与 `BASE` 表，按原顺序规范化 GPOS 的字形索引，再用 `instantiateVariableFont(font, {"ROND": 40, "wght": (400, 700)})` 生成保留字重轴的版本。修改后的内嵌字体使用独立字体家族名称。

开局配置、设置、科技树与外交使用全屏页面。菜单、上下通栏和选中面板的内容居中，宽度上限为当前窗口高度。上栏显示回合、星星、收入、城市、单位和分数。底栏依次为设置、外交、科技、结束回合，有待选升级时从结束回合按钮进入奖励。选中对象后，同色通栏从底栏上方展开，上行直接显示操作，下行同时显示详情，两行均可横滑。城市直接提供训练及升级奖励，建造设施从对应地块操作。局内设置提供重置视角。

上下通栏和选中面板使用纯色底板。操作按钮加大图标，用压边、面板高光和底部厚边表现重量，按下时向底座压入。结束回合按钮采用暖金色面板。按钮材质随象牙白与深蓝主题切换。

底栏四个主按钮等宽。点击按钮时按钮短促回弹。结束回合采用 Material Design 2 式的半透明填充波纹，圆面先在按钮内展开，随后扩及棋盘并淡出。全屏菜单与对话窗开启时缓入，关闭时保留短暂的淡出画面，操作目标与焦点立即交回下层界面。

首页背景直接使用 `设定/bg.png`，通过 CSS `cover` 随视口等比裁切。标题与操作组直接叠在背景图上，中央使用淡出的半透明渐变提高可读性。低高度窗口收紧行距，必要时可纵向滚动。科技树在横屏和竖屏共用同一星形布局，拖动平移，双指或滚轮缩放，亦可用全图按钮回到总览。点节点会在底部显示科技简介、费用和前置条件，树上节点位置保持固定。再点同一个可研究的节点才执行研究。

只有城市显示名称，紧凑的名牌沿屏幕中线贴近模型下沿。可见城牌的底板和中立村落一致，使用 28% 不透明度，城名及收入文字独立绘制并保持完全不透明。生命值与城牌收入同字号。陆军的数字贴在棋子底座上沿，舰船的数字放在船体靠镜头一侧的水面上，距离随船型调整。数字使用无底色的象牙色与深色描边，低血量使用浅珊瑚色。点按城名或血量的覆盖区域时，点击落到下方的棋盘或棋子。双箭头提示城市升级，旗标提示占领，奖章提示晋升，罗盘提示探索遗迹，回转箭头提示欠费单位重新激活。激活标记在可补缴的整个回合内显示。点击标记打开对应的城市或单位。同格出现两项提示时，分别点选各自的标记。结束回合按钮与 Enter 会先定位尚未完成选择的城市。

己方城市有待交付的训练订单时，城顶显示小钟。时钟随视角移动，与可点按的行动徽标错开，轻触可以穿透。

第一次点可攻击的目标时，选中面板显示预计伤害、反击与双方生命值变化，目标棋子脚下显示红色光圈。再次点同一目标格执行攻击。改点另一名可攻击的敌军会切换预估，按 Esc 会退出预估并保留攻击者的选择。

## 棋盘与棋子

棋盘采用削边格面、木质边框与黄铜嵌线。正交相机锁定俯仰角和方位角，拖动平移，滚轮和双指捏合缩放。单指或鼠标拖动时即时跟手，快速释放后沿原方向滑行并指数减速，衰减时间常数为 0.21 秒。选中格用金色柔光圈边，攻击目标用珊瑚红，移动范围用绿色。势力边界沿用国家资源包的高亮识别色和略加粗的实线。移动和攻击提示的描边与指示点使用 70% 不透明度。五种地形各使用一套帝国外观，棋盘和开局预览共用底色。近景的空平原和空水面各有固定位置的低草和浅色弧纹。点缀避开玩家已知的资源、建筑和道路，共享几何实例并随远景隐去。山地、平原与海洋共用三级台座高度。以平原为基准，山地高出 0.12 格宽，海面低 0.105 格宽。森林与平原同高，深浅水同高。单位、弹道、道路、建筑和徽标共用 `src/scene/terrainElevation.ts`。选中、移动、攻击光圈和势力边界在独立图层绘制。边界遇到台阶时沿立面接合。

棋盘通过透明画布呈现在银河底图上。场景采用略偏中性的照明，模型颜色在 sRGB 下微调明度与饱和度。其他阵营的可见领地及其中的模型轻微压暗，已用尽行动的棋子采用单独的行动暗度。

己方领土内符合采集条件的可见资源使用浅金色光晕。屏幕遮罩将描边限制在资源模型的整体外缘，林地中的动物和背景树木各用自己的模型。提示取决于科技、领地和驻军等采集条件，星星余额只影响实际采集。

陆军采用十九世纪末至二十世纪初的架空近代军容。风格 B 棋子使用无五官的小方头、车木般的衣摆、贴颈的窄立领、胸前单扣与肩下挎带。制服色按兵种分组，帽型和圆盘色标识阵营。诺斯塔的毛皮帽沿同一倾斜平面收边，铃亚的青绿双角帽比通用帽型更收敛。骑手、炮手与车长使用同一套人物。棋盘缩小时优先用醒目的装备轮廓辨认兵种：国民步兵的木托枪、猎兵的带镜长枪、突击步兵的长刺刀、战壕工兵的宽铲、战地军医的救护箱、便衣侦探的双筒镜、地下突击队的短刀。轻骑兵以短卡宾枪和轻装马具辨认，胸甲骑兵以高举的军刀和胸甲辨认。野战炮队突出大型辐条轮和长炮管，重型装甲车以包覆轮组和大炮塔区分。

侦察船为细长尖艏的卡拉维尔帆船，用两面三角帆、斜伸艏桅和木制尾楼辨认。撞击艇由三艘低矮的尖艏鱼雷快艇编队表示。轰炸舰用窄铁甲舰体、宽斜烟囱和显眼的前主炮，无畏舰用独立宽舰体、阶梯炮台、双烟囱和三脚观测桅。木筏、小艇和海盗船分别以绑扎浮木、带桨开敞艇、深色帆和矮尾楼辨认。[葡萄牙卡拉维尔馆藏模型](https://www.rmg.co.uk/collections/objects/rmgc-object-66267) · [无畏舰三脚桅照片](https://www.rmg.co.uk/collections/objects/rmgc-object-1020218)

每块林地共用青绿针叶与苔绿阔叶混合的低矮林丛。果树三簇呈三角分布，麦穗四簇分占田角，三簇矿石沿蓝灰岩层前缘分散，两小群林鹿分立林缘的两侧。果丛用红橙点色，麦穗用暖金，矿石用铜金，鱼群和珊瑚色海星各有自己的轮廓。每种资源和地貌分别烘焙到一个网格，供显示、描边和采集反馈复用。实现位于 `src/scene/landscape.ts` 与 `src/scene/tidalResources.ts`。运行 `npm run dev` 可用[图集试片](http://127.0.0.1:5173/agent/scripts/fish-atlas.html)烘焙多面鱼群。

设施从对应的原生地块发展出来。伐木屋在原林地前侧开辟集材场，保留后排与侧面四棵树的原坐标、树型和大小，被砍的两棵树在原处留下树桩。农场保留四簇原生麦穗，田垄、打谷与装袋工位围绕麦田布置。矿场在原山体前坡切出坑口，保留山脊和两侧露天矿脉，中间一脉的矿料装入矿车。施工和升档时，保留下来的树木、岩坡、麦田与矿脉固定在地表。码头栈桥按已探索的岸线接坡，水面纹理留在装卸面外缘。

城外 20 类可建设施均有三档，对应所属城市 1–2 级、3–4 级、5 级及以上。一档为初建场地，二档发展为配有动力、加工与仓储设施的完整工场。三档在二档工场上扩建成区，农场增加筒仓与谷物升运塔，采矿区增加井架和筛矿台，港口增设跨泊位龙门吊，桥梁形成上承横撑连接的穿式桁架。市场发展为批发街区，纪念设施发展为庭院、园区或临水配楼。设施和道路按同一辖区同时升档。工矿区用柱跨、成排窗带、天窗、连接料道和装卸设备形成厂房与工场群。伐木屋突出原木和集材机械，锯木厂突出锯床、送料线与成品板材，锻造厂突出炉膛和烟道，港口突出临水货栈、起重臂和泊位。屋面以旧锌板、灰绿板材和风化木色为主，局部用切面木色、矿石色、炉火和窗带区分工作面。市场为带装卸月台的交易所，城外祭祀场所保留钟、龛、碑等用途明确的主体。

设施入口是 `src/nations/_shared/danubian/buildings.ts`，农林工矿造型位于 `workyards.ts`，市场和纪念设施位于 `civicGrounds.ts`，港口与桥梁位于 `waterworks.ts`。城外建筑专用色板在 `ruralKit.ts`。设施的费用、产出和游戏等级由规则层计算。

帝国为每一级城镇提供四种造型。各级城市最高的主楼保留原有造型和位置，其余楼宇按四套布局更换。街巷、院落和配楼的数量、体量与屋顶轮廓随布局变化。五级用连续低层街屋围出街区，六级以成片高楼形成不同天际线。城市变体由地图种子和地块坐标确定，旧存档可当场派生。中立村庄使用固定地块所属国的资产，易主后的城市使用现任所属国的资产。地块和设施统一用帝国造型，保留地块存档内的资产包 ID。每类设施有三档外观，每档采用固定配色和造型。

道路表面低贴地形，转角采用弧形铺装，省去路口已由直向接通的对角支路。已解锁的道路在地块操作列表中排首位。己方港口之间从已探索且可通行的水域选出航线，海面以浅色虚线标记。一组相通的港口展示最短连接网络。

## 动效原则

移动和行动分别按兵种规则判断。选中单位后，首次点击高亮的相邻友军会预览换位，棋盘只框出双方所在格。再点同一格确认，双方各消耗一次移动。己方棋子可作为中间格穿越。单位详情在特性旁显示击杀进度，晋升后显示老兵。猎兵移动后如有可攻击目标，会保持选中，轻骑兵和胸甲骑兵也可继续合法的撤离或连击。用尽可用动作后取消选中并压暗棋子。

陆军底座是一块带金色外镶边的圆盘。圆盘面、舰船条带和旗帜与领土边界共用本国高亮色。陆军头部和帽子以颈部为共同锚点缩至原尺寸的 85%。衣襟、胸甲、马身、炮塔和船板使用独立的三角切面。

陆军与舰船在地块与建筑之后绘制。己方棋子和可采集资源共用浅金色光晕，描边沿棋子完整投影的外缘绘制，重叠部件和其他棋子的可见表面保持模型原色。用尽可用动作后撤下光晕并加深模型和底座的暗度。敌军使用完整原色。兵种内部和相邻棋子按深度排序，点击相叠的模型时优先选择可见棋子。单位只使用朝向镜头的左、右 45° 两种姿态，移动按起点与终点的屏幕横向关系选择朝向，攻击和受击时转向可见对手所在一侧。横向对齐或攻击来源藏在迷雾中时保留原朝向。

单位详情从特性按钮开始，再显示攻击、防御、移动和射程。点特性可打开对应说明，生命值由棋盘上的数字显示。突击步兵的「驻防」在己方城市内提供城防加成。

选中城市、资源格或设施格时，用灰色虚线和浅灰光晕标出所属城市已探索的领地外沿。轮换选中单位时收起范围提示。

可见的敌对部队抵达城市时，低多边形的火焰和浓烟出现在街边，城模使用单独的围城暗度。守军解围、敌军撤离或城市易主后恢复正常。和平阵营、中立聚落和视野外的围城不会产生提示。减少动画时保留静态火焰和烟。

规则先确定操作结果，渲染层在前后快照之间做短过渡。回放需要切换位置时，镜头从当前视角缓入缓出地平移，抵达后播放下一步可见行动。两次可见行动之间留一小段间隔。移动、攻击朝向、受击、死亡与训练反馈由场景负责；界面按钮、弹窗、侧栏和进度条使用短 CSS 过渡。动画不参与规则计算，也不延迟资源与存档结算。

星星、回合、分数、单位数、战斗数值和其他变化的数值在原位短促跃动。城市人口条按变化填充或回退，已占用的单位位随增减弹入弹出。升级先填满旧人口条，再切换到新容量显示剩余人口。棋盘生命值在命中的一刻跳动。

增加人口的行动带有来源和目的城。采集直接把被消耗的资源模型抛入城市，矿场和农场等设施抛出矿石、作物等产物。资源沿短抛物线飞行，在抵达城市时缩到零，落点的金色闪光随后消散。己方操作继续按规则结算，其他阵营的可见飞行随逐步回放展示。

城市、建筑和道路的出现、拆除和外观变化由行动前后两个快照确定。换模先下沉约 0.36 秒，停顿 0.065 秒，再上升约 0.54 秒，露出的部分随地表高度裁切。同一行动引起的城市与附属设施变化同步展示，后续行动等待整步完成。城市易主时切换城市模型和领土色，档位相同的设施与道路留在原位。读档与拖动镜头直接显示当前造型。具体见 `src/store/structurePlayback.ts` 和 `src/scene/TileScenery.tsx`。

道路以 2.2 倍速播放同类换模。重型装甲车奖励和遗迹奖励挤开的棋子沿普通移动曲线进到相邻地块，敌方位移的显示受战争迷雾限制。

设置中的“减少动画”保留为可选入口。迷雾之外的敌人行动不可通过过渡动画泄漏；大地图按可见区域渲染，避免为了动画挂载整张地图的单位模型。

棋子先提起，再沿合法路线滑行，抵达后回落轻弹。直走一格用 0.50 秒，多格行程最长 0.78 秒，换位用 0.58 秒。近战棋子短暂后撤蓄力，底座或船艏碰撞时压身，受击方回弹或倒下。需要反击时，双方回稳后再交换角色。击杀后可进格的棋子会从碰撞后短促回弹的位置继续向前，随倒下的棋子退场完成落地。攻击距离考虑棋子体量与驻军站位。猎兵、野战炮队、侦察船和轰炸舰抬起发射，再按武器分别表现后坐，伤害表现与落点同步。猎兵和野战炮队分别使用步枪弹和炮弹，并在可见枪口显示短暂火光。射手或路径被迷雾遮挡时，来袭方向取与其坐标无关的短轨迹。减少动画时保留武器名和伤害。战斗跟随场景播放时钟，在低帧率下会放慢，切换至后台会暂停。
