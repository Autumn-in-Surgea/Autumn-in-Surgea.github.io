# 界面配色与动效

2026-11-18 更新对局界面、菜单尺寸与触屏操作。

## 配色依据

选用艺术配色网站 [Color Lisa](https://colorlisa.com/#V) 收录的 Johannes Vermeer《The milkmaid》色板作为基底。网站给出的五色为 `#022F69`、`#D6C17A`、`#D8D0BE`、`#6B724B`、`#7C3E2F`。

这是设计选择：深蓝与暖金能承接宫廷感，石色与绿能融入地形，赭红适合重要反馈。为了在小屏幕与三维地图上长期阅读，实际 UI 使用经明度、饱和度调整的衍生色，而不是宣称原作使用了下面的屏幕色值。

| 用途 | 屏幕色 |
| --- | --- |
| 对局通栏和菜单页眉 | `#22394F`、`#101F32` |
| 正文 | `#243C42` |
| 面板、象牙白 | `#F5F0E3` |
| 旧金强调 | `#B59A55` |
| 绿与地形辅助色 | `#4D7162` |
| 危险、赭红 | `#914C3E` |
| 环境背景 | `#D5DCD6` |

浅色界面采用象牙白细纹、深蓝文字和旧金镶边。深色界面采用深蓝底与象牙色文字。主菜单、对局上下栏、选中面板、全屏菜单和特性弹窗共用主题，可跟随系统或由玩家手动切换。

## 字体与地图操作

对局与常规面板使用两档字号：大号 `20px`，小号 `14px`，由 `src/styles/main.css` 中的 `--font-size-large` 和 `--font-size-small` 维护。主菜单是字号例外。中文和英文标题优先使用系统宋体粗体，中文在常规窗口为 52–94px、英文为 21–32px。标题与等宽等高的主菜单按钮居中竖排，每行一个按钮。对话框标题沿用同一套宋体配置；按钮、正文、对局顶部和地图标签使用 Resource Han Rounded 简体中文版，圆度固定为 `40`。顶部各项统一小号，用字重和颜色区分重点。城名和兵人血量与棋格等比缩放，战斗反馈使用 14px 的屏幕字号。

标题按系统字体可用性依次尝试 Songti SC、STSong、SimSun 等宋体，以及常见的 Noto Serif CJK SC。标题使用 700 字重，只有常规字重的系统字体允许合成粗体。缺少系统字形时使用 Resource Han Rounded。圆体来自 [Resource Han Rounded v1.910](https://github.com/CyanoHao/Resource-Han-Rounded/releases/tag/v1.910)，用 OpenType 的 `ROND` 轴生成 `40` 的 WOFF2 子集，随其 SIL OFL 1.1 许可证一同分发与预缓存。

重新生成网页字体时，用 FontTools（含 WOFF2/Brotli）从上述版本取源文件，保留 UI 用字、基本拉丁字符和 GB 2312。圆体网页子集移除仅用于垂直排版的表与 `BASE` 表，按原顺序规范化 GPOS 的字形索引，再用 `instantiateVariableFont(font, {"ROND": 40, "wght": (400, 700)})` 生成保留字重轴的版本。修改后的内嵌字体使用独立字体家族名称。

开局配置、设置、科技树与外交使用全屏页面。菜单、上下通栏和选中面板的内容居中，宽度上限为当前窗口高度。上栏显示回合、星星、收入、城市、单位和分数。底栏依次为设置、外交、科技、结束回合，有待选升级时从结束回合按钮进入奖励。选中对象后，同色通栏从底栏上方展开，上行直接显示操作，下行同时显示详情，两行均可横滑。城市直接提供训练及升级奖励，建造设施从对应地块操作。局内设置提供重置视角。

首页背景直接使用 `设定/bg.png`，通过 CSS `cover` 随视口等比裁切。标题与操作组直接叠在背景图上，中央使用淡出的半透明渐变提高可读性。低高度窗口收紧行距，必要时可纵向滚动。科技树在横屏和竖屏共用同一星形布局，拖动平移，双指或滚轮缩放，亦可用全图按钮回到总览。

只有城市显示名称，名牌沿屏幕中线放在模型下方。仅显示名称时使用 38% 不透明度的深灰底，带人口条时使用 74% 不透明度的深蓝底。生命值使用无底色的象牙色粗体和深色描边，低血量使用浅珊瑚色。点按城名或血量的覆盖区域时，点击落到下方的棋盘或棋子。双箭头提示城市升级，旗标提示占领，奖章提示部队可晋升老兵。点击标记打开对应的城市或单位。同格出现两项提示时，分别点选各自的标记。结束回合按钮与 Enter 会先定位尚未完成选择的城市。

第一次点可攻击的目标时，选中面板显示预计伤害、反击与双方生命值变化，目标棋子脚下显示红色光圈。再次点同一目标格执行攻击。改点另一名可攻击的敌军会切换预估，按 Esc 会退出预估并保留攻击者的选择。

## 棋盘与棋子

棋盘采用削边格面、木质边框与黄铜嵌线。正交相机锁定俯仰角和方位角，拖动平移，滚轮和双指捏合缩放。选中格用金色柔光圈边，攻击目标用珊瑚红，移动范围用绿色。势力边界沿用原阵营色，采用略加粗的实线。移动和攻击提示的描边与指示点使用 70% 不透明度。同一地块变体内的五种地形各有一种底色，三维棋盘和开局预览按坐标绑定的变体 ID 读取同一套国家资产。浅海和深海各自通铺。近景中，部分空平原有几片低草，空水面有一对浅色弧纹。点缀按格子位置固定，避开玩家已知的资源、建筑和道路，按实际几何共享实例并随远景隐去。山地、平原与海洋共用三级台座高度。以平原为基准，山地高出 0.12 格宽，海面低 0.105 格宽。森林与平原同高，深浅水同高。单位、弹道、道路、建筑和徽标共用 `src/scene/terrainElevation.ts`。选中、移动、攻击光圈和势力边界在独立图层绘制。边界遇到台阶时沿立面接合。

棋盘通过透明画布呈现在银河底图上。场景采用略偏中性的照明，模型颜色在 sRGB 下微调明度与饱和度。其他阵营的可见领地及其中的模型轻微压暗，已用尽行动的棋子采用单独的行动暗度。

己方领土内符合采集条件的可见资源使用细金边提示。描边沿资源模型轮廓绘制，林地里的动物和背景树木各用自己的模型。提示取决于科技、领地和驻军等采集条件，星星余额只影响实际采集。

陆军模型收窄头部与腰身，加长双腿，站立棋子双脚并拢。灰蓝外衣用象牙色和明亮的金属细节勾出轮廓，帽型、武器与装备区分兵种，底座沿用阵营色。制服采用奥匈式立领与骑兵帽，融合二战时期德国军服的折边短檐和利落剪裁。模型不含政治符号，五官留白，剑士、心灵术士和巨人保留少量胡须切面。[奥匈制服图录](https://www.awm.gov.au/collection/LIB37968) · [萨尔茨堡博物馆藏 M.1908 野战帽](https://sammlung-online.salzburgmuseum.at/detail/collection/401e934a-baa3-4491-b1d3-cdf657f6d39f) · [短檐野战帽馆藏记录](https://collection.awm.gov.au/C104752)

侦察船为细长尖艏的卡拉维尔帆船，用两面三角帆、斜伸艏桅和木制尾楼辨认。撞击艇由三艘低矮的尖艏鱼雷快艇编队表示。轰炸舰用窄铁甲舰体、宽斜烟囱和显眼的前主炮，无畏舰用独立宽舰体、阶梯炮台、双烟囱和三脚观测桅。木筏、小艇和海盗船分别以绑扎浮木、带桨开敞艇、深色帆和矮尾楼辨认。[葡萄牙卡拉维尔馆藏模型](https://www.rmg.co.uk/collections/objects/rmgc-object-66267) · [无畏舰三脚桅照片](https://www.rmg.co.uk/collections/objects/rmgc-object-1020218)

六种资源都使用多面低模。果树、鱼群和林鹿是基础采集物，果树宽约 0.326 格，保留三个红果，林鹿放在树丛靠相机的一侧。作物与矿石供二阶科技建设农场和矿场，采用金色麦穗与深岩上的浅金矿脉。导航解锁采集海星，珊瑚色腕部在深水上最醒目。这是美术层次，沿用已有的资源分布、显示与采集规则。实现位于 `src/scene/landscape.ts` 与 `src/scene/tidalResources.ts`。运行 `npm run dev` 可用[图集试片](http://127.0.0.1:5173/agent/scripts/fish-atlas.html)烘焙当前的多面鱼群；对局直接绘制网格。

## 动效原则

移动和行动分别按兵种规则判断。选中单位后，首次点击高亮的相邻友军会预览换位，再点同一格确认，双方各消耗一次移动。己方棋子可作为中间格穿越。弓箭手移动后如有可攻击目标，会保持选中，骑手和骑士也可继续合法的撤离或连击。用尽可用动作后取消选中并压暗棋子。

陆军与舰船在地块与建筑之后绘制。己方棋子的浅白光晕沿完整棋子投影的外缘绘制，重叠部件和其他棋子的可见表面保持模型原色。用尽可用动作后撤下光晕并加深模型和底座的暗度。敌军使用完整原色。兵种内部和相邻棋子按深度排序，点击相叠的模型时优先选择可见棋子。单位只使用朝向镜头的左、右 45° 两种姿态，移动按起点与终点的屏幕横向关系选择朝向，攻击和受击时转向可见对手所在一侧。横向对齐或攻击来源藏在迷雾中时保留原朝向。

单位详情从特性按钮开始，再显示攻击、防御、移动和射程。点特性可打开对应说明，生命值由棋盘上的数字显示。剑士的「驻防」在己方城市内提供城防加成。

选中城市时，单独用灰色虚线和浅灰光晕描出已探索的领地外沿。轮换选中城内单位时撤下城市提示，地块内边保持空白。

规则先确定操作结果，渲染层在前后快照之间做短过渡。回放需要切换位置时，镜头从当前视角缓入缓出地平移，抵达后播放下一步可见行动。两次可见行动之间留一小段间隔。移动、攻击朝向、受击、死亡与训练反馈由场景负责；界面按钮、弹窗、侧栏和进度条使用短 CSS 过渡。动画不参与规则计算，也不延迟资源与存档结算。

城市、建筑和道路的出现、易主、替换及升级由行动前后两个快照确定。换模先下沉约 0.36 秒，停顿 0.065 秒，再上升约 0.54 秒，露出的部分随地表高度裁切。同一行动引起的城市与附属设施变化同步展示，后续行动等待整步完成。读档与拖动镜头直接显示当前造型。具体见 `src/store/structurePlayback.ts` 和 `src/scene/TileScenery.tsx`。

设置中的“减少动画”保留为可选入口。迷雾之外的敌人行动不可通过过渡动画泄漏；大地图按可见区域渲染，避免为了动画挂载整张地图的单位模型。

近战棋子先后撤蓄力，再加速冲向对方，底座或船艏接触时结算画面上的伤害。受击棋子会后退或倒下，进攻棋子回弹，反击时交换角色。进攻距离考虑两枚棋子的体量与驻军站位。先移动再攻击时，动作沿同一时间轴衔接。弓箭手、投石车、侦察船和轰炸舰仍用箭矢、石弹、弩矢与炮弹，伤害表现与落点同步。射手或路径被迷雾遮挡时，来袭方向取与其坐标无关的短轨迹。减少动画时保留武器名和伤害。战斗跟随场景播放时钟，在低帧率下会放慢，切换至后台会暂停。
